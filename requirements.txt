# Install the CUDA build first:
#   python -m pip install torch==2.10.0 \
#     --index-url https://download.pytorch.org/whl/cu128
# The verified runtime reports torch.__version__ == "2.10.0+cu128".
# importlib.metadata reports "2.10.0" without the local version suffix.
#
# TM-align is a required external executable, not a Python package or a
# binary bundled with this repository. The reward path invokes `TMalign`
# by name, so it must resolve from PATH.
# Verified installation:
#   conda install -c conda-forge -c bioconda tmalign=20220227
# Verify with:
#   command -v TMalign && TMalign -h
# Source-build alternative using the official 2022-04-12 source:
#   curl -L https://zhanggroup.org/TM-align/TMalign.cpp -o TMalign.cpp
#   g++ -static -O3 -ffast-math -o TMalign TMalign.cpp -lm
#   install -m 0755 TMalign /a/directory/on/PATH/TMalign
# Omit -static on macOS or systems without static libc.
#
# ESMFold requires OpenFold, which is not on PyPI and needs a source build.
# Verified installation path (OpenFold v2.1.0,
# commit f434a2786b5a6b39171f358fb3470ad9f4fd2a58):
#   REPO=/absolute/path/to/ProteinZero
#   git clone https://github.com/aqlaboratory/openfold && cd openfold
#   git checkout f434a2786b5a6b39171f358fb3470ad9f4fd2a58
#   patch -p1 < "$REPO/patches/openfold-v2.1.0-cxx17.patch"
#   patch -p1 < "$REPO/patches/openfold-v2.1.0-tuple-index.patch"
#   python -m pip install . --no-build-isolation
#   python -m pip install -r "$REPO/requirements.txt"
#   ESM_SITE_PACKAGES="$(python -c \
#     'import esm; from pathlib import Path; \
#      print(Path(esm.__file__).resolve().parent.parent)')"
#   patch -p1 -d "$ESM_SITE_PACKAGES" \
#     < "$REPO/patches/fair-esm-2.0.0-openfold-v2.1-key-remap.patch"
#
# pip 26 enables build isolation, but OpenFold setup.py imports torch during
# its build, so the already-installed CUDA torch must remain visible.
# fair-esm 2.0.0 references OpenFold revision 4b41059, which is unusable with
# PyTorch 2.10: its build fails under both C++14/C++17 and its
# pytorch_lightning imports are incompatible.
# Reinstalling by the path above was not bitwise identical to the original
# runtime: on 2guzA, mean pLDDT differed by one float32 ULP and the maximum
# atom37 coordinate difference was about 2e-05 Angstrom. This is below the
# 1e-03 Angstrom PDB coordinate grid used before TM-align and therefore does
# not affect TM-score or its downstream reward.
# In the original verified runtime, two independent same-GPU seed-42 folds
# of 2guzA were bitwise identical in mean pLDDT, atom37 coordinates and mask.
